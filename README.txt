Aminat Afolabi portfolio · static site, no build step

1. Open site.js and fill in PROFILE at the top: email, CV link (or drop your CV PDF in this folder and put its file name), X link.
   Anything left empty stays hidden on every page.
2. Deploy the whole folder as a static site. On Vercel: push to GitHub, import the repo, framework preset "Other", no build command.
3. Optional: once you have a domain, change og:image in each page's <head> to the full address (https://yourdomain/og-image.png)
   so LinkedIn and WhatsApp previews always show the image.
